# Amir Rosen - Executive CV & Portfolio Web Application

אתר וקורות חיים אינטראקטיביים למנהלים בכירים ומנכ״לים (C-Level & Board Members).
מציג את ניסיונו המקצועי, הטכנולוגי והעסקי של **אמיר רוזן** - Chief AI Officer בבנק לאומי, לשעבר מנכ״ל Irani Ventures וסמנכ״ל טכנולוגיות.

## ✨ מאפיינים וטכנולוגיה
- **עיצוב Executive High-End & Mobile-First:** חוויית משתמש מותאמת באופן מושלם לסמארטפונים, טאבלטים ומסכי מחשב.
- **סוכן AI ניהולי אינטראקטיבי:** סוכן מובנה המאפשר למנכ״לים ומנהלים בכירים לשאול שאלות ולקבל מענה מיידי וממוקד על הישגיו של אמיר.
- **סיקור תקשורתי ומדיה עשירה (30 קישורים):** שילוב קישורי עיתונות (TheMarker, מעריב, וואלה), ראיונות וידאו (טרסטק), תובנות לינקדאין ופוסטים מרכזיים בכרטיסי תצוגה מקדימה עשירים (OpenGraph style).
- **ציר זמן תעסוקתי אינטראקטיבי:** סינון מהיר לפי קטגוריות (AI, בנקאות, Retail, ענן, ביטחון), חיפוש טקסט חופשי, ואקורדיון מתקדם (Expand / Collapse).
- **האדם מאחורי המנהיגות:** פרק אישי ייחודי המציג את הערכים, המחויבות והעוגן המשפחתי.
- **מצבי תצוגה:** תמיכה במצב כהה (Executive Dark) ומצב בהיר (Executive Light) בלחיצת כפתור.
- **ייצוא והדפסה:** תמיכה מלאה בהדפסה נקייה ומותאמת כ-PDF.
